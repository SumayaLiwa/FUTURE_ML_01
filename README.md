# Sales & Demand Forecasting for Businesses

## Machine Learning Internship Task 1
This project was completed as part of the Machine Learning Internship Program at Future Interns.

## Project Overview
Sales forecasting is an important application of Machine Learning used by businesses to predict future demand. Accurate forecasts help organizations plan inventory, manage resources, and make better financial decisions.

In this project, a simple Machine Learning model is built to forecast future sales using historical monthly sales data.

## Objectives
- Analyze historical sales data
- Prepare time-based features
- Train a machine learning model for forecasting
- Visualize sales trends and predictions
- Provide business insights from the forecast

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Data Preparation  
   Historical sales data was created and structured with date and sales values.

2. Data Cleaning  
   The dataset was converted into a proper date format and time-based features such as month and year were extracted.

3. Model Training  
   A Linear Regression model was used to learn the relationship between time and sales.

4. Forecasting  
   The trained model predicts future sales for upcoming months.

5. Visualization  
   Sales trends and predicted values are visualized using graphs to make the forecast easier to understand.

## Results
The model shows an upward sales trend, indicating that sales are gradually increasing over time.

## Business Insights
Businesses can use this forecasting approach to:

- Plan inventory levels
- Manage staffing requirements
- Estimate future revenue
- Avoid overstocking or stock shortages

## Conclusion
This project demonstrates how Machine Learning can support business decision-making through sales forecasting. Even simple models can provide valuable insights when applied to historical data.
